# docs

All written material for the project. Read in this order if you are new:

1. [architecture.md](architecture.md): the components, how data flows, and why each decision was made.
2. [strategy.md](strategy.md): the exact trading rules with parameters and a worked example.
3. [requirements.md](requirements.md): how to set up the machine.
4. [api/](api/): Alpaca endpoint notes with sample responses.
5. [decisions.md](decisions.md): the decision log, one entry per technical choice.
6. [features/](features/): one plain-English page per feature as each is built.
7. [research/](research/): dated experiment write-ups from the backtester.
8. [roadmap-advanced-strategies.md](roadmap-advanced-strategies.md): where higher P/L can come from and what the app needs for each candidate strategy.
9. [vision-autonomous-quant.md](vision-autonomous-quant.md): the end goal, what is realistic, the target architecture and build sequence.
10. [handbook.md](handbook.md): the all-in-one chapter-wise reference (strategies with formulae and worked examples, architecture, protocol, risk, operations, results). Also published as a shareable doc; the repo copy is exported from it.
