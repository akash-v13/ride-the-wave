# Chapter notes

Raw distillations of Dixon, Halperin & Bilokon (2020), written 2026-09-17 by four parallel readers from
the text of `docs/books/machine-learning-in-finance-*.pdf`. Each carries printed page references and a
section on applicability to Ride The Wave; inferences that are ours, not the book's, are marked. The
topic files one level up are the curated version; come here for detail or to check a citation.

- `notes-ch01-02.md`: introduction, statistics vs ML, over-fitting, Bayesian estimation, model selection.
- `notes-ch04-06.md`: training/validation/testing, interpretability, sequence modelling and diagnostics.
- `notes-ch07-08.md`: HMMs, Kalman/particle filters, RNN/LSTM/CNN with financial examples.
- `notes-ch09-10.md`: reinforcement learning foundations and applications (QLBS, G-learning, wealth).

Page-number caveat: the readers found the extraction's "printed ~m" markers one or two pages high; all
notes cite the running-header (true printed) numbers.
